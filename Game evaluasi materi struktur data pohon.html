Misi 1 • Mindful & Meaningful

Mengapa Harus Struktur Tree?

+100 XP

Skenario Realita: Bayangkan kamu menyimpan 10.000 file tugas di laptopmu. Jika semua file ditaruh berurutan dalam satu baris tanpa folder (Struktur Linear), pencarian file akan memakan waktu sangat lama!

Dengan Struktur Data Tree (Pohon Bertingkat), file dikelompokkan ke dalam Folder Utama (Root) dan Sub-Folder (Subtree), sehingga komputer dapat menemukan file dalam hitungan milidetik.

Tantangan: Susun Berkas ke Folder Hirarki yang Bener!

Refleksi Mindful Berhasil!

Struktur bertingkat (Tree) membuat pencarian data lebih efisien karena komputer tidak perlu memeriksa satu per satu dari awal, melainkan langsung menuju cabang yang relevan.

Misi 3 • Mathematical Thinking

Kapasitas Pohon Biner (Binary Tree)

+150 XP

Aturan Pohon Biner

Pada Pohon Biner, setiap simpul induk paling banyak memiliki 2 anak (Left Child & Right Child).

Rumus Jumlah Maksimal Node pada Kedalaman (k): N = 2k - 1

Simulasi Kedalaman Level (k)

Kedalaman (k) 3
Max Node (2k-1) 7

Tantangan Hitung Cepat Komputasional

Jika sebuah Pohon Biner Sempurna memiliki kedalaman k = 4 level, berapa jumlah maksimum node yang bisa ditampungnya?

Benar! Untuk k = 4, 2⁴ - 1 = 16 - 1 = 15 Node!
